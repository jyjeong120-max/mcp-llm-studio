      기억 불러오는 중…

        저장된 기억을 개별(✕) 또는 전체 삭제할 수 있습니다. 되돌릴 수 없으며, 이후 대화에서 다시 학습합니다. (활성 프로젝트가 있으면 그 프로젝트 기억을, 없으면 기본 공간 기억을 보여줍니다. 개별 대화 압축은 채팅 상단의 🗜 버튼을 쓰세요.)

        로컬 LLM 서버 (모델을 골라 서빙을 시작/중지합니다)

        이미 떠 있는 llama-server(serve_llm.py 등)에 붙습니다. 앱을 껐다 켜도 그 서버는 유지됩니다.

        외부 LLM 연결 (OpenAI 호환 API — 키는 서버 config.json에만 저장, 브라우저에는 남지 않음)

        chat/completions 규격이면 무엇이든 등록 가능. 저장은 하단 [설정 저장] 버튼으로 함께 저장됩니다.

        MCP 도구 서버

        MCP는 위 [MCP 저장 + 재연결] 버튼으로 따로 저장합니다 (하단 [설정 저장]과 별개).

        저장될 JSON 미리보기

        위 폼이 원본입니다. 직접 손보려면 데이터 폴더의 mcp_servers.json을 편집하세요.
